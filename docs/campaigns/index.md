# Explore HSSM by question

These paths turn public HSSM evidence into a useful next step. They do not add
claims beyond the linked paper, release, documentation, code, or reproducible
artifact.

| If your question is… | Start here | Then do this |
|---|---|---|
| What is HSSM and how should I cite it? | [Paper and citation](../index.md#citation) | [Run the quickstart](../getting_started/getting_started.ipynb) |
| What changed, and will my model need migration? | [Release and migration guide](releases.md) | Read the exact [changelog](../changelog.md) |
| Which mechanism or validation question can the models address? | [Method and model stories](methods.md) | Reproduce a linked tutorial or figure |
| Could this support an organizational decision? | [Decision-support boundary](decision-support.md) | Review [use and licensing](../use-and-licensing.md) before proposing a scoped evaluation |
| Is an explanation, tutorial, or visual missing? | [Content suggestions](../community/content-suggestions.md) | Submit a public, evidence-linked idea |

HSSM is publicly available scientific software, not a clinically validated
biomarker or regulator-approved decision system. A proposed use remains a
hypothesis until its context, data, diagnostics, operating characteristics and
review are explicit.
